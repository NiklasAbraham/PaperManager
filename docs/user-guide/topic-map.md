# Topic map

**Explore → Topic map** (`/topic-map`) shows your whole library as one map: every paper with an embedding is a dot, and
papers that are about similar things sit close together. The map fills the page; the settings are on the right (on a
phone, tap **Settings** for a bottom sheet). Every setting is kept in the address, so you can link a view or reload it.

## Reading the map

- Big dots are your library papers; small faint dots are references (cited papers without a PDF).
- **Hover** a dot for its title, topic and year; **click** to open the paper.
- **Drag** to pan, **Ctrl/⌘ + scroll** (or pinch) to zoom, or use **+ / −**; **Reset zoom** appears once you zoom in.
- The legend under the map matches the colour setting.

## Settings

| Setting | What it does |
|---|---|
| Colour by | **Cluster** (default), **Project**, **Year** (light to dark scale), **Reading status**, or **None** |
| References | Show or hide the cited papers (library papers only / both) |
| Cluster labels, label size | Turn the labels on or off and change their size |
| Dot size, dot opacity | Sliders |
| Number of clusters | 4 to 16 (default: automatic). The first time you pick a number the map is re-clustered in the background ("Re-clustering…"), and the result is remembered |
| Projects | Check one or more projects: each gets a soft bubble in its colour, the rest fades |
| Year from / to | Hide papers outside the range |
| Highlight titles containing | Dims every paper whose title does not contain all the words |
| Reset | Back to the defaults |

Labels never reveal papers you cannot see: for non-admin users they are derived from papers that are in no project.

## Export

**Export PNG** downloads `topic-map-YYYY-MM-DD.png` at 2× (**PNG 4×** for print): the current view with your settings,
zoom and highlights, the legend and a title, on a white background. **Copy image** puts the same picture on the
clipboard (browsers that allow it, on https or localhost).

The Library page's map card has an **Open full map ↗** link.
