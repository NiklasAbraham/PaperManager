## Text

```
I asked my paper library how AlphaFold 3 predicts a protein complex.

It did not guess. It wrote graph queries against my own library, found the 28 papers in it that cite AlphaFold 3, pulled 16 of the paper's figures and showed the SARS-CoV-2 spike in 3D. Every answer links back to its sources, and every tool call is visible, so you can check how it got there.

That is the chat in PaperManager, the open-source paper library I build next to my thesis. It reads from one knowledge graph of your papers, notes and citations, so the next question starts where the last one ended.

Free, self-hosted, open source: https://niklas-abraham.de/projects/papermanager/

What would you ask your own library first?

#OpenSource #Research #KnowledgeGraph #SelfHosted
```
